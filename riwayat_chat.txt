5.1 IMPLEMENTASI

5.1.1 Listing Program

Listing program memuat representasi modul-modul inti PHP yang mengimplementasikan arsitektur MVC, abstraksi basis data PDO Singleton, formulasi kalkulasi keterlambatan real-time, transaksi otomasi Auto-Alpha, serta algoritma kriptografi hash SHA-256.

a. Modul Autentikasi dan Manajemen Sesi (controllers/AuthController.php)
Modul ini menangani validasi kredensial pengguna (Admin, Dosen, Mahasiswa), verifikasi password hash, proteksi session fixation (`session_regenerate_id(true)`), dan pembuatan cookie sesi aman.

b. Modul Presensi Mandiri Mahasiswa (controllers/PresensiController.php)
Modul ini bertugas menangani aksi mahasiswa saat menekan tombol presensi mandiri, menghitung selisih waktu keterlambatan terhadap jam mulai perkuliahan, menetapkan status (HADIR/TERLAMBAT), serta mengunci record dengan integrity hash SHA-256.

c. Modul Penutupan Sesi & Otomasi Auto-Alpha (controllers/PresensiController.php)
Modul ini mengeksekusi algoritma Set Difference di dalam transaksi atomik PDO (`beginTransaction`, `commit`, `rollBack`). Mahasiswa anggota kelas yang belum hadir saat dosen menutup sesi secara otomatis diisi status `ALPHA` beserta nilai hash SHA-256 yang valid.

d. Modul Verifikasi Integritas Data Kriptografis (controllers/AuditController.php)
Modul ini bertugas melakukan audit keutuhan data presensi. Sistem membaca data dari database, menghitung ulang hash SHA-256 secara independen (*Computed Hash*), lalu membandingkannya dengan hash yang tersimpan di basis data (*Stored Hash*) untuk mendeteksi manipulasi ilegal.

e. Modul Helper Enkripsi & Format Kriptografi (helpers/FormatHelper.php)
Menyediakan fungsi terpusat untuk kalkulasi hash SHA-256 dengan format string terstandarisasi serta fungsi pemformatan tanggal, waktu, dan persentase kehadiran.

f. Modul Koneksi Basis Data Terpusat (config/database.php)
Mengimplementasikan *Singleton Pattern* pada PDO (*PHP Data Objects*) dengan opsi `ATTR_ERRMODE => ERRMODE_EXCEPTION` dan `ATTR_DEFAULT_FETCH_MODE => FETCH_ASSOC` guna mencegah SQL Injection dan mengoptimalkan penggunaan memori server.

g. Modul Front Controller dan Routing Aplikasi (index.php)
Berfungsi sebagai pintu masuk utama (*Single Entry Point*) yang menangani seluruh permintaan HTTP GET/POST dan mengarahkannya ke controller yang tepat menggunakan *match expression* PHP 8.

h. Modul Laporan Rekapitulasi & Export Kehadiran (controllers/LaporanController.php)
Memproses rekapitulasi persentase kehadiran mahasiswa per kelas, akumulasi status (Hadir, Terlambat, Izin, Sakit, Alpha), serta menggenerasi dokumen laporan siap cetak/PDF.

Perhitungan & Formulasi Algoritma Toleransi Keterlambatan dan Hash SHA-256
----------------------------------------------------------------------

1. Formulasi Penentuan Status Keterlambatan:
   Selisih keterlambatan (Delta t) dihitung dari selisih waktu submit presensi (T_submit) dan waktu mulai kelas (T_mulai), dikonversi ke satuan menit:
   Delta t = (T_submit - T_mulai) / 60  (menit)

   Status kehadiran ditentukan dari Delta t terhadap nilai toleransi keterlambatan (T_tol):
   - Jika Delta t <= T_tol                 --> Status = HADIR
   - Jika T_tol < Delta t <= 2 * T_tol      --> Status = TERLAMBAT
   - Jika Delta t > 2 * T_tol              --> Status = ALPHA

2. Formulasi Hash Integritas (SHA-256):
   Hash = SHA256(Nama | NIM | Tanggal | Sesi_MK | Jam | Hari | Status)
   Contoh: Dimas Anggara|230003|2026-08-04|MWFC008|08:00-10:30|Senin|HADIR

5.1.2 Implementasi Sistem
----------------------------------------------------------------------
Implementasi Sistem Informasi Presensi Perkuliahan dilakukan pada lingkungan pengembangan lokal menggunakan sistem operasi Windows 10/11 di atas platform Laragon/XAMPP. Sistem dibangun menggunakan bahasa pemrograman PHP versi 8.1+ dengan arsitektur Model-View-Controller (MVC) murni dan DBMS MySQL 8.0.

Aspek teknis utama implementasi meliputi:
1. Lingkungan Server & Arsitektur Aplikasi: Pola Front Controller pada index.php mengarahkan permintaan HTTP secara responsif berbasis match expression PHP 8.
2. Pengelolaan Koneksi Basis Data (PDO Singleton Pattern): Menggunakan satu objek koneksi PDO aktif dan prepared statements untuk mencegah SQL Injection.
3. Logika Perhitungan Toleransi & Kriptografi SHA-256: Kalkulasi selisih waktu real-time server clock dan penguncian signature hash SHA-256 64-karakter pada setiap record kehadiran.
4. Otomasi Status Auto-Alpha & Transaksi Database: Transaksi PDO atomik (beginTransaction, commit, rollBack) dengan algoritma set difference untuk meng-alpha-kan mahasiswa yang tidak hadir.
5. Manajemen Otentikasi & Keamanan Sesi Multi-Role: Pembatasan ketat wewenang 3 peran (Admin, Dosen, Mahasiswa) serta mitigasi Session Fixation via session_regenerate_id(true).

5.1.4 Instalasi Sistem
----------------------------------------------------------------------
A. Instalasi Konfigurasi Basis Data
   1. Mengaktifkan layanan Apache dan MySQL melalui kontrol panel Laragon/XAMPP.
   2. Membuat database `sistem_presensi` dengan enkoding `utf8mb4_unicode_ci`.
   3. Mengimpor tabel dan data awal via `sistem_presensi.sql` atau `install.php`.
   4. Mengonfigurasi parameter koneksi pada `config/database.php` berbasis PDO Singleton.

B. Instalasi Aplikasi Web Presensi Perkuliahan (PHP Native MVC)
   1. Menempatkan repositori proyek ke direktori web root (`C:\laragon\www\sistem_presensi`).
   2. Mengatur konstanta `BASE_URL` di `config/config.php` ke `http://localhost/sistem_presensi`.
   3. Mengaktifkan ekstensi PHP `pdo_mysql`, `openssl`, dan `mbstring` di `php.ini`.
   4. Menetapkan hak akses tulis folder `uploads/` untuk foto profil pengguna.

C. Instalasi Dashboard Monitoring & Antarmuka Multi-Role
   1. Menata hierarki `views/` dan file front controller `index.php`.
   2. Menjalankan routing Apache ke halaman login `http://localhost/sistem_presensi/?page=auth`.
   3. Memvalidasi alur dashboard Admin, Dosen, dan Mahasiswa melalui HTTP POST/GET.

D. Instalasi Mesin Validasi Integritas SHA-256 & Transaksi Auto-Alpha
   1. Memastikan modul `helpers/FormatHelper.php` aktif memproses `hash('sha256', $data)`.
   2. Mengonfigurasi parameter keterlambatan dan hashing di `PresensiController.php`.
   3. Memastikan modul `AuditController.php` siap memindai dan mendeteksi anomali hash di MySQL.

BAB VI: KESIMPULAN DAN SARAN
======================================================================

6.1 Kesimpulan
1. Sistem informasi presensi mahasiswa berhasil dibangun dan mampu menghasilkan nilai hash unik untuk setiap data kehadiran yang disimpan. Sistem secara otomatis membangkitkan nilai hash SHA-256 64-karakter heksadesimal berdasarkan 7 elemen presensi untuk pemeriksaan integritas data.
2. Mekanisme verifikasi integritas data menggunakan algoritma SHA-256 berhasil diterapkan untuk memastikan keaslian data presensi di FTI UNIBBA melalui perbandingan rekalkulasi hash (Hash Match vs Hash Mismatch).
3. Pengujian manipulasi langsung pada basis data MySQL menunjukkan tingkat keberhasilan deteksi perubahan ilegal sebesar 100%.

6.2 Saran
1. Integrasi Kombinasi Algoritma Kriptografi Lanjutan (Dynamic Salt, HMAC Secret Key, atau Digital Signature).
2. Evaluasi Performa pada Infrastruktur Cloud (VPS / Docker) dan Migrasi ke Framework Modern (Laravel/CI4).
3. Perluasan Objek Data yang Di-hash serta Integrasi Geofencing GPS & Biometrik Face Recognition.
4. Penambahan Notifikasi Otomatis Multi-Channel (WhatsApp Gateway / Telegram Alert) dan Backup Cloud Berkala.
